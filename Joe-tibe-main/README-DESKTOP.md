# JoeTube كبرنامج سطح مكتب (ويندوز)

**كيف يعمل:** Electron يشغّل داخل البرنامج نفس الـ API (Express) على `127.0.0.1` ويعرض الواجهة.
الاستخراج يخرج من **إنترنت جهازك** (عنوان منزلي)، فلا يحظره يوتيوب كما يحظر Vercel وCloudflare.
لا خادم خارجي ولا يلزم شيء مفتوح غير البرنامج نفسه. الأيقونة والشعار مأخوذان من `public/pwa-512x512.png`.

## الطريقة 1: بناء الـ exe على GitHub (الأسهل، بدون إعداد محلي)
1. ارفع المشروع إلى GitHub.
2. تبويب **Actions** ← **Build Windows Desktop App** ← **Run workflow**.
3. بعد دقائق نزّل `JoeTube-Windows` من Artifacts، وفيه:
   - `JoeTube-Setup-1.0.0.exe` (مثبّت بشعار البرنامج واختصار على سطح المكتب)
   - `JoeTube-Portable-1.0.0.exe` (نسخة تعمل بدون تثبيت)

## الطريقة 2: البناء على جهازك (Node 22+)
```powershell
npm install
npm run desktop:dist
```
الناتج في `desktop\release\` (المثبّت `JoeTube-Setup`). للنسخة المحمولة: `npm --prefix desktop run dist:portable`. للتجربة بدون بناء مثبّت: `npm run desktop:start`.

إذا ظهر خطأ `Cannot create symbolic link` أثناء البناء المحلي: شغّل PowerShell **كمسؤول (Run as administrator)**،
أو فعّل **Developer Mode** من إعدادات ويندوز، ثم أعد الأمر.

## أين تُحفظ الملفات؟
`Downloads\JoeTube\` تلقائيًا، مع إشعار عند الاكتمال (الضغط عليه يفتح المجلد). القائمة العلوية ← التنزيلات ← فتح المجلد.

## yt-dlp
سكربت البناء ينزّل `yt-dlp.exe` ويضعه داخل البرنامج (بديل أقوى عند فشل الطريقة الأولى). لتخطي ذلك: `SKIP_YTDLP=1`.

## تغيير الشعار
استبدل `desktop/build/icon.png` و`desktop/build/icon.ico` (الـ ico يجب أن يحتوي مقاس 256×256) ثم أعد البناء.

## ملاحظات
- أول تشغيل قد يعرض ويندوز تحذير SmartScreen لأن البرنامج غير موقّع رقميًا: «مزيد من المعلومات» ← «تشغيل على أي حال».
- لا يوجد ffmpeg: الصوت يُقدَّم بصيغته الأصلية (M4A)، والفيديو MP4 بصوت مدمج، كما في بقية النسخ.
- لم أستطع تشغيل Electron ولا بناء الـ exe من بيئتي (لا شبكة)؛ اختبرت الخادم المحلي بـ Node فقط.

## الجودات والصوت (نسخة سطح المكتب)
- **جودات حقيقية:** تُقرأ الجودات المتاحة فعلًا من yt-dlp (مثل 2160p/1440p/1080p/720p/480p/360p)، ويُدمج الفيديو مع الصوت بواسطة ffmpeg المضمَّن.
- **MP3 حقيقي:** تحويل فعلي بـ ffmpeg (وليس M4A باسم MP3). وخيار M4A متاح كملف أصلي بدون إعادة ترميز.
- **الحفظ:** `Downloads\JoeTube`، مع شريط تقدّم (تحميل ← دمج/تحويل).
- بعد تغيّر يوتيوب إن تعطّل التحميل: القائمة ← التنزيلات ← **تحديث محرك التحميل (yt-dlp)**.

## ستوريهات إنستغرام
الستوريهات (وحتى الحسابات العامة) **تتطلب تسجيل دخول**، لذلك:
1. القائمة ← التنزيلات ← **الستوريهات وتسجيل الدخول**.
2. اختر **ملف cookies.txt** (الأضمن) أو **كوكيز متصفح** مسجَّل الدخول فيه (Firefox هو الأنسب؛ Chrome/Edge على ويندوز غالبًا لا تُقرأ بسبب تشفير جديد).
3. الصق رابط الستوري `instagram.com/stories/اسم_الحساب/…` وحمّل. رابط `…/stories/اسم_الحساب/` بدون رقم يحمّل كل ستوريهات الحساب.

تنبيهات: ملف الكوكيز يعادل تسجيل دخولك فلا تشاركه، وإنستغرام قد يقيّد الحساب المستخدم فيُفضَّل حساب ثانوي. ستوريهات الصور قد لا تنجح مع yt-dlp في كل الحالات.
نسخة الويب (Vercel/Cloudflare) لا تدعم الستوريهات إطلاقًا لأنها بلا تسجيل دخول.
